These are project-owned aggregate module-model, effect, coverage and synthetic-classification tables copied from the already frozen development record. No expression, donor-level scores or cell identifiers are included. Source/public hashes and normalization are in the content-provenance register. These cases were selected during development, not randomly sampled from a literature population.

Public text is normalized to LF for cross-platform Git consistency. H1 coordinates preserve the original local-byte SHA in `local_frozen_source_sha256` and bind `source_sha256` to the public LF-normalized source. Numeric values and model fields are unchanged. This distinction avoids falsely requiring different line-ending byte representations to share a hash.
