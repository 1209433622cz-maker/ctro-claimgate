# Reproducibility and data boundaries

## Publicly reproducible here

- the public repository manifest;
- the gate matrix and study-status table;
- parsing and validation of the public ENG04 input contract;
- confirmation that the public package contains no prohibited data extension;
- documentation of the current decisions and stop rules.
- the public Stage57 integrity and synthetic-planning summary;

## Reproducible only in the controlled local workspace

- full-file and duplicate inventories;
- raw archive and source-manifest audits;
- donor/cell reconciliation against downloaded source material;
- pinned Git-object reconstruction;
- compatibility-environment smoke tests;
- deterministic reconstruction of local metadata candidates.
- exact Stage55–57 source-archive and release-package replay;

## Not yet reproducible

- the exact historical ENG04 CellPhoneDB input export;
- the exact author runtime database selection;
- any original disease-effect result under the author pipeline;
- the formal R1 corpus, coding, agreement, or primary endpoint.
- any external expert opinion, reviewer roster, consent, conflict record, or dispatch receipt.

## Why files are excluded

Exclusion is based on privacy, license, provenance, size, and study-blinding constraints. The absence of a source file from GitHub does not imply that it was unavailable locally; the public repository is a deliberate derivative view.

Stage57 planning values are published only as validation summaries. They are assumption-based diagnostics, not observed eligibility rates, confidence intervals, or claim-evidence results.
